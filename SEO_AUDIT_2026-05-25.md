# Wildsaura SEO/Indexing Audit (2026-05-25)

This report documents an external technical review request for:
- https://www.wildsaura.com
- https://www.wildsaura.com/photo/yellow-magnolia-bloom

## Key findings

1. Strong signal that the site is an SPA where Google is currently indexing primarily the homepage and not deep `/photo/` detail URLs.
2. Homepage content is discoverable in search snippets, but there is weak evidence of indexed photo detail pages.
3. Likely root causes are JavaScript-only rendering and metadata/canonical not being emitted in initial HTML for each route.

## Evidence gathered

- Search snippet for homepage contains rich, human-readable hero/body text, indicating at least the homepage is indexed and content can be rendered.
- No reliable direct extraction of live raw HTML source for route-level pages from this environment; follow-up with URL Inspection + cURL from your environment is required for exact tag-level verification.

## Priority fixes

1. Add SSR or prerendering for all indexable routes (`/photo/:slug`).
2. Ensure route-specific server-rendered `<title>`, `<meta name="description">`, canonical, and OG tags.
3. Ensure all photo pages are linked from crawlable HTML and present in sitemap.
4. Validate robots.txt does not block `/photo/` or supporting assets.
5. Add structured data (`ImageObject`) per photo page.
